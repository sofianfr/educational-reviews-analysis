## Лингвостатистический анализ стратегий выражения благодарности и критики (по материалам онлайн-отзывов в сфере преподавания иностранного языка)


Дипломный проект, НИУ ВШЭ, 2026 год.
Специализация: Компьютерная лингвистика.

## Данные
- Источникb: Profi.ru, Avito, Яндекс.Услуги
- Объем: 1 162 отзыва, 40 755 токенов
- Файл: `reviews_corpus.csv`

## Методы
- Частотный анализ лексических маркеров
- Статистическая проверка гипотез (критерий χ² Пирсона)
- Корреляционный анализ (коэффициент φ)
- Качественный прагматический анализ

## Ключевые результаты
- При низких оценках (1–3 балла) доля критики достигает 87–92%
- При высоких оценках (5–6 баллов) преобладает благодарность (79–86%)
- Выявлена сильная корреляция между лингвистическими маркерами и рейтингом (φ=0.67 для благодарности, p<0.001)

## Инструменты

- Pandas
- Статистические критерии (χ², p-value)
